# rust-aprendizaje

Ejercicios y entregables del plan "Rust para apps de escritorio".

- `fase-N/`: un proyecto por ejercicio. Desde la raíz: `cargo new fase-0/hola`, `cargo run -p hola`.
- `rustlings/`: `cd rustlings` y después `rustlings`. El progreso queda en el repo.
- Libro oficial sin internet: `rustup doc --book`.

En otra PC: instalar rustup, MSVC Build Tools y `cargo install rustlings`, y clonar.
